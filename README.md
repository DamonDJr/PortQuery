# Port Query

A toon-shaded 3D data-detective adventure that teaches SQL and SAS.

## Play (Windows)

1. Go to the [latest release](../../releases/latest) and download `PortQuery-windows.zip`.
2. Unzip the whole folder anywhere.
3. Double-click `PortQuery.exe`.

Keep `sqlite3.exe` next to `PortQuery.exe`; the SQL missions use it.
Windows SmartScreen may warn about an unknown publisher because the game isn't code-signed. Click **More info → Run anyway**.

*This repo only hosts the playable build, not the source.*
